# 브뤼헐의 놀이터 VR

피터르 브뤼헐(父)의 〈아이들의 놀이〉(1560) 속 광장으로 들어가, 17가지 놀이를 하는 아이들을 가까이서 보는 WebXR 체험입니다. A-Frame 1.6 단일 HTML 파일이며 Meta Quest 3 브라우저에서 바로 실행됩니다.

## 실행
- GitHub Pages 주소: `https://yejusihae.github.io/main/bruegel-vr/`
- 퀘스트 3 브라우저에서 위 주소를 열고 오른쪽 아래 **VR** 버튼을 누르세요.

## 조작
| 퀘스트 3 | 동작 |
|---|---|
| 트리거 | 바닥 가리켜 순간이동 · 그림 선택 |
| 왼쪽 스틱 | 걷기 |
| 오른쪽 스틱 | 30° 회전 |
| A / B | 다음 / 이전 놀이로 이동 |
| X | 갤러리로 돌아가기 |
| Y | 설명 패널 켜기/끄기 |

PC: 드래그로 둘러보기, WASD 걷기, 클릭 순간이동, N/P 놀이 이동, G 갤러리.

## 그림 속 아이들
광장의 아이들은 3D 모형이 아니라 **원화에서 한 명씩 오려 낸 인물**입니다(종이 인형처럼 항상 관람자를 향해 섭니다). 굴렁쇠 소년, 죽마 타는 아이, 공기놀이 소녀, 종이 관을 쓴 신부 등 35개 인물·무리를 배경 제거 모델로 오려 `figures.webp` 한 장(아틀라스)에 담았습니다. 움직이는 방향에 따라 좌우로 뒤집히고, 굴렁쇠·팽이·공깃돌·구슬 같은 소품은 3D로 함께 움직입니다.

## 원화 이미지
갤러리 액자는 같은 폴더의 `childrens-games.jpg`(위키미디어 공용, 퍼블릭 도메인)를 씁니다. 불러오지 못하면 위키미디어에서 직접 받고, 그것도 안 되면 구도 스케치를 보여 줍니다.
